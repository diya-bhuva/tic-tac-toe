# Tic-Tac-Toe Game ❌⭕️

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- ❌⭕️ Two-player gameplay
- 🔄 Automatic turn switching
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 Reset Game functionality
- 🆕 New Game option
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open `TicTacToe.html` in your web browser.
2. Player O starts the game.
3. Players take turns clicking an empty box.
4. The first player to get three matching symbols in a row wins.
5. If all 9 boxes are filled without a winner, the game ends in a draw.
6. Click **Reset Game!** to start a new game.

## 🧠 Game Logic

The game checks all possible winning combinations:

- Horizontal rows
- Vertical columns
- Diagonal combinations

A player wins when the same symbol occupies all three positions of any winning combination.

## 🔄 Game Controls

- **Reset Game!** → Clears the board and starts a new game.
- **New Game!** → Starts a fresh game.
